Politique de Confidentialité - Affiliés & Parrainage

Dernière mise à jour : Février 2026

1. Introduction

Dans le cadre de notre Programme de Parrainage (Yélim Parrainage), la protection de vos données en tant qu'affilié, parrain ou influenceur est essentielle. Cette politique spécifique complète notre Politique de Confidentialité générale et détaille le traitement de vos données liées aux activités de parrainage.

2. Les Données que nous collectons

2.1. Informations de profil

  • Identité et Contact : Nom, prénoms, numéro de téléphone et adresse e-mail.
  • Informations financières : Coordonnées de paiement (numéros Mobile Money tels que Orange, Moov, Wave, etc.) pour le versement de vos commissions sur les demandes de retrait.

2.2. Données d'activité et de parrainage

Pour assurer le bon fonctionnement de la rémunération et l'attribution des filleuls, nous suivons :

  • Les utilisateurs (filleuls) qui s'inscrivent en utilisant votre code de parrainage.
  • Le nombre total de vos filleuls et l'historique de vos récompenses / commissions générées.
  • Vos demandes de retraits de gains, incluant les statuts (en attente, validée, refusée) et les montants.

3. Utilisation de vos données

Vos données d'affilié sont utilisées pour les finalités suivantes :

  • Gestion du programme : Suivre et comptabiliser les inscriptions issues de votre code.
  • Rémunération : Traiter vos demandes de retrait et vous transférer les fonds gagnés via les moyens de paiement mobile.
  • Communication : Vous notifier de la validation de vos retraits, de l'évolution du programme, ou pour tout support associé au parrainage.

4. Partage des données

Les données liées à vos performances de parrainage ou vos commissions sont strictement confidentielles. Elles ne sont partagées qu'avec :

  • Les opérateurs de paiement : Uniquement les informations nécessaires pour exécuter les transferts de fonds lors de vos retraits (Mobile Money).
  • Nos administrateurs : Via l'application Yélim Admin pour valider les demandes de retrait et surveiller la prévention des fraudes.

5. Visibilité par vos Filleuls

Lorsque vos filleuls utilisent votre code de parrainage à l'inscription ou pour des commandes, votre identité publique (prénom ou pseudo d'influenceur) peut être affichée pour confirmer que le code a bien été appliqué.

6. Vos droits

Vous avez le droit de demander l'accès à l'historique complet de vos données de parrainage, ou de demander la fermeture de votre compte affilié depuis l'application Yélim Parrainage. En cas de suppression de compte, les gains non réclamés pourraient être perdus conformément à nos Termes et Conditions d'Affiliation.
