# Historical Monde De L’electro batch

Use this reference only when resuming or correcting the electro batch that established these values. It is historical campaign evidence, not a universal default for other vendors.

## Campaign values

- Canonical vendor: `Monde De L’electro`.
- Sale price equalled purchase price until later user editing.
- `quantiteLimite = 5`.
- `quantiteLimiteExpedition = 2`.
- `prixLivraison = 1000`.
- `prixExpedition = 1000`; air fryer exception `2000`.
- `fraisTransportPourLivrerALaGare = 1000`.
- Air conditioners: `peutEtreExpedier = false`.
- `poidsColis = "léger"`.
- `delaiLivraison = "2 heures"`.

The annotated supplier images were evidence for price and specification. Clean white-background images were the publication images.

## Final structure learned from the batch

The correct outcome was eight articles rather than fifteen:

- Bouilloire électrique Decakila 1.8L.
- Plaque chauffante Decakila with power variants.
- Micro-ondes Decakila with capacity variants.
- Fer à repasser Decakila 2400W.
- Mixeur Roch 1.5L.
- Foyer automatique 3 feux.
- Air fryer Decakila 8L.
- Climatiseur Nasco R32 with combined model variants.

When one supplier image lists multiple prices for the same visual product, default to a variant review, not duplicate article documents.
